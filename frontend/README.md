# Pet Shop Frontend

Фронтенд интернет-магазина товаров для животных на React (Create React App).

## Структура проекта

- `src/components` — переиспользуемые компоненты (карточки товаров, формы и т.д.)
- `src/pages` — компоненты страниц (главная, категория, товар и т.д.)
- `src/layouts` — общий макет (шапка, подвал)
- `src/ui` — базовые UI-элементы (кнопки, инпуты)

## Установка и запуск

```bash
npm install
npm start
```

Приложение запустится на `http://localhost:3000` и будет ходить за данными на backend (`http://localhost:3333`).
